# Gravity Shooter - プレイマニュアル

## 🎮 起動方法
パッケージ同梱の `GravityShooter.exe` を起動してください。

---

## 🕹️ 基本操作方法

| 操作 | キー / マウス | 動作内容 |
| :--- | :--- | :--- |
| **自機移動** | **W / A / S / D**（または **方向キー**）<br>※ゲームパッド：**左スティック** | レール局所断面での上下左右の回避運動 |
| **照準 / レティクル** | **マウス移動** | 画面内のマウスカーソル位置にレティクルが追従 |
| **ガレキ引き寄せ** | **E キー** | 周囲の漂流ガレキ（またはボスのシールド）を引き寄せて自機周囲に浮遊展開 |
| **ロックオン (マーキング)** | **マウス右クリック** | レティクル内の敵やボスシールドをロックオン（所持ガレキ数まで連続ロック可） |
| **ロックオン解除** | **R キー** | 現在キューに入っているロックオン対象をすべてクリア |
| **ガレキ投擲 / 攻撃** | **マウス左クリック** または **Q キー** | ガレキを射出（ロック時は対象へ誘導、非ロック時は正面へ1発発射） |
| **ポーズ** | **ESC** | ポーズメニューの開閉 |
| **全画面 / ウィンドウ切替** | **F11** または **Alt + Enter** | 画面表示モードの切り替え |

## 🚀 ゲームシステム・攻略のポイント

### 1. ガレキの捕獲と展開
- **Eキー** を押すと、周囲に漂うガレキを自機の周囲に引き寄せることができます。
- 引き寄せたガレキは自機の周囲を回転しながら追従し、攻撃用の弾薬としてストックされます。

### 2. ロックオンとマルチ投擲
- 敵やボスのシールドに照準を合わせ、**マウス右クリック** でターゲットをロックオン（マーキング）します。
- **マウス左クリック**（または **Qキー**）で、ロックオンした対象へ向けてガレキを連続誘導射出します。
- ノーロック状態で左クリックを押すと、正面へ向けて単発で射出します。

### 3. ボスのシールド剥奪
- ボスが展開しているガレキシールドを右クリックでロックオンし、**Eキー** で引き寄せることで、ボスのシールドを奪い取って自分の弾薬に変換できます。
- シールドを剥がして露出した弱点コアを狙い撃つことで、大ダメージを与えられます。

### 4. 敵の予兆（Telegraph）回避
- スナイパー敵が放つ赤色レーザーが激しく点滅・固定されたら、直後に高威力の偏差弾が発射されます。素早く上下左右（WASD）へ軸をずらして回避してください。

## ⚙️ 動作環境
- **OS**: Windows 10 / 11 (64bit)
- **DirectX**: DirectX 12 対応グラフィックスカード (GeForce RTX 2060 相当以上推奨)
- **画面解像度**: 1920x1080 推奨
