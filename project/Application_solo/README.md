# Gravity Shooter - プレイマニュアル

## 🎮 起動方法
パッケージ同梱の `GravityShooter.exe` を起動してください。

---

## 🕹️ 基本操作方法

### バトル操作
| アクション | キーボード / マウス | ゲームパッド (Xbox系) | 動作内容 |
| :--- | :--- | :--- | :--- |
| **自機移動** | **W / A / S / D** (または 方向キー) | **左スティック** | レール断面上の上下左右へ自機を移動・回避 |
| **照準 / レティクル** | **マウス移動** | **右スティック** | 画面内のターゲットへ照準を合わせる |
| **ガレキ引き寄せ / 吸収** | **E キー** | **LT** (左トリガー) / **LB** | 周囲の浮遊ガレキやボスシールドを引き寄せて弾薬化 |
| **ロックオン (マーキング)** | **マウス右クリック** | **RB** (右バンパー) / **A ボタン** | レティクル内の敵やシールドをロック (所持弾数分マーク可) |
| **ガレキ投擲 / 射撃** | **マウス左クリック** / **Q キー** | **RT** (右トリガー) | ガレキを射出 (ロック時は誘導、ノーロック時は正面単発) |
| **ロックオン全解除** | **R キー** | **B ボタン** | キューにあるロックオン対象をすべてクリア |
| **ポーズメニュー** | **ESC** | **START ボタン** | ポーズ画面の開閉 |
| **全画面 / 窓切替** | **F11** / **Alt + Enter** | - | ウィンドウ / ボーダーレス全画面の切り替え |

### メニュー / オプション操作
| 操作 | 入力デバイス | 動作内容 |
| :--- | :--- | :--- |
| **仮想カーソル移動** | **マウス** / **左・右スティック** | 画面上のカーソルを移動 (スティック浅倒しで精密操作) |
| **選択 / 決定** | **マウス左クリック** / **A ボタン** / **SPACE** | ボタンの押下、スライダーのドラッグ開始 |
| **スライダー微調整** | **D-PAD (十字キー左右)** | 音量・スティック感度を 1% 単位で微調整 |
| **戻る / キャンセル** | **マウス左クリック (CLOSE)** / **B ボタン** / **ESC** | 前の画面へ戻る |

## 🚀 ゲームシステム・攻略のポイント

### 1. ガレキの捕獲と展開
- **Eキー** または **LT / LB** を入力すると、周囲に漂うガレキを自機の周囲に引き寄せることができます。
- 引き寄せたガレキは自機の周囲を回転しながら追従し、攻撃用の弾薬としてストックされます。
- ※周囲に浮遊ガレキがなく弾数がゼロの場合、緊急ガレキが前方に出現するフェイルセーフ機能が作動します。

### 2. ロックオンとマルチ誘導射出
- 敵やボスのシールドに照準を合わせ、**マウス右クリック** または **RB / Aボタン** でターゲットをロックオン（マーキング）します。
- **マウス左クリック** / **Qキー** / **RTトリガー** で、ロックオンした対象へ向けてガレキを連続誘導射出します。
- ノーロック状態で射撃すると、正面へ向けて単発で直進射出します。

### 3. ボスのシールド剥奪 (Shield Steal)
- ボスが展開しているガレキシールドに照準を合わせ、**Eキー** または **LT** で引き寄せることで、ボスのシールドを奪い取って自分の弾薬に変換できます。
- シールドを剥がして露出した弱点コアを狙い撃つことで、大ダメージを与えられます。

### 4. 敵の予兆（Telegraph）回避
- スナイパー敵が放つ赤色レーザーが激しく点滅・固定されたら、直後に高威力の偏差弾が発射されます。素早く上下左右（WASD / 左スティック）へ軸をずらして回避してください。

## ⚙️ オプション機能 (OPTIONS)
タイトル画面の「OPTIONS」より各種設定をリアルタイムに変更できます。
- **BGM VOLUME**: BGM音量の調整
- **SE VOLUME**: 効果音音量の調整
- **STICK SENSITIVITY**: ゲームパッド操作時の仮想カーソル移動速度（250 px/s 〜 1250 px/s）を調整可能

## 💻 動作環境
- **OS**: Windows 10 / 11 (64bit)
- **DirectX**: DirectX 12 対応グラフィックスカード (GeForce RTX 2060 相当以上推奨)
- **画面解像度**: 1920x1080 推奨 (16:9)
- **対応コントローラー**: Xbox コントローラー / XInput 対応ゲームパッド
